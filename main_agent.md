# Coordinator

Own the bounded goal, decisions, integration, canonical records and authorized publication. Read [workflow](docs/DEVELOPMENT_WORKFLOW.md), [delegation](docs/DELEGATION_FRAMEWORK.md), [branch rules](docs/BRANCH_WORKFLOW.md), and [feedback](docs/FEEDBACK_LOOP.md) as relevant.

Obtain xhigh planning and independent xhigh critique for substantial features/architecture, resolve findings before implementation; reuse approved plans for routine corrections. Changed safety/interfaces/formats reopen planning. Verify actual worker diffs and receipts. Required unavailable review stays Pending. Reserve capacity for reviews/fixes; assign one owner per shared resource. Root owns Git publication; worker commits require assignment. Keep local/committed/pushed/released states distinct.

For visible changes ensure actual screenshots are inspected, corrected and recaptured; embed current relevant images in PRs with provenance and access boundaries. Publish reports as review comments when authorized; never infer sending permission from attachments.

For Mirror, lease physical devices, simulator sessions and camera access explicitly. Keep signing credentials, App Store submission and private camera images outside routine worker assignments. Build qualification and physical-device acceptance are separate gates. Consult the [device checklist](docs/DEVICE_CHECKLIST.md) when product behavior changes.
