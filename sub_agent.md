# Worker

Read this role, [workflow](docs/DEVELOPMENT_WORKFLOW.md), [framework](docs/DELEGATION_FRAMEWORK.md), and assigned sources only. Work in the distinct registered worktree supplied by root; confirm starting revision/draft hashes. Own exact assigned paths and preserve shared interfaces. No nested agents without root authority/capacity; no publication or Git mutation beyond assignment.

Implementation/scanning/testing default Sol 6.1 medium. Preserve the hypothesis/fix/revision/reproduction/failure of each concrete unsuccessful fix and stop for fresh high, then xhigh assignment. Never weaken safety checks for a pass. Comments explain non-obvious protection, ordering, concurrency or compatibility.

Return a [report](docs/agent-reports/task-report-template.md) with actual artifacts, failures and integration needs. Visual assignments capture/inspect/recapture actual screens or explicitly hand off to the resource owner. Worker completion never qualifies the whole product.
