# Delivery audits

During active work, audit every two hours and at each meaningful full checkpoint using a fresh Sol 6.1 xhigh report-only auditor. Record exact UTC recurring/full-package boundaries and dispatch time; keep overlapping windows separate. Scheduling is opt-in: use actual automation tools and read back creation before claiming it is active. If unavailable, record Pending and perform active-work checks.

Bound evidence; report at most five prioritized findings and three actions. Compare verified fixes, integrated functionality, feedback time and avoidable waiting/coordination. Unknown activity/utilization remains Unknown. Root records adopted/deferred/disagreed findings and reasons; later evidence checks effects. No-progress audits stay short and do not displace implementation. [Reports](agent-reports/task-report-template.md) retain receipts and next steps.
