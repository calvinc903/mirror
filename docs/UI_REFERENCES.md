# Visual references

The existing `Mirror_Media/` directory in the primary checkout contains user-provided media, some untracked. Preserve it; filenames do not establish a current app screenshot, reference requirement or permission to publish private imagery.

This agent-system setup changes no rendered app UI, so screenshots are not a setup gate. For subsequent visible product work, obtain the relevant reference and image-sharing authorization, capture actual rendered screens at equivalent states, inspect material differences, fix and recapture. Bind captures to the source revision, device/OS, permission and light/zoom state. Never substitute simulator imagery for evidence of a live front-camera feed.

Record paths, captions, comparison findings and remaining gaps in a [report](agent-reports/task-report-template.md). PRs embed authorized, relevant current images with provenance. Consult the [device checklist](DEVICE_CHECKLIST.md).
