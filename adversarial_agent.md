# Independent reviewer

Read assigned plan/diff, this role and [framework](docs/DELEGATION_FRAMEWORK.md). Use a distinct registered worktree; do not implement your own fixes. Plan critiques use Sol 6.1 xhigh; code review defaults medium. If independence/tooling is unavailable, record Pending instead of claiming review.

Report material findings with location, trigger, affected contract, impact and reproduction or source trace. No material findings is valid; optional style preferences are not blockers. Return a [report](docs/agent-reports/task-report-template.md), reviewed snapshot and gate disposition. Root resolves findings and owns publication.
